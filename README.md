# legal

Public legal documents for the BeeyondApps Revit add-ins, served via GitHub Pages.

These URLs go into the **Privacy Policy** field of each Autodesk Design and Make Marketplace
listing. They must stay reachable **without signing in** — Autodesk's review opens them, and a
policy it cannot read is grounds for rejection.

| Document | URL |
|---|---|
| HeightMatch — Privacy Policy | https://caglarbiber90.github.io/legal/heightmatch-privacy.html |
| RoomShell — Privacy Policy | https://caglarbiber90.github.io/legal/roomshell-privacy.html |
| PlanShip — Privacy Policy | https://caglarbiber90.github.io/legal/planship-privacy.html |

Source of truth for each file is `docs/privacy-policy.html` in the corresponding add-in
repository — edit there first, then copy here and push.

## Why not beeyondapps.com

The company site runs on Wix (classic Editor). Wix has no REST API that creates a page from
raw HTML, so publishing there means opening the Wix editor and building each page by hand.
This repo is already public with Pages built, so it stays the practical home. If the pages are
ever moved to the company domain, update the three listing URLs at the same time.
